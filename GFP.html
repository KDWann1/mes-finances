Sécurité

      
Vos données sont chiffrées (AES-256) avec votre code d'accès et ne quittent jamais cet appareil. L'application se verrouille après 5 minutes en arrière-plan. Sans le code, les données sont irrécupérables.

      

        
        
        
        
      

      

    

    

      
Sauvegarde

      
Vos données sont stockées uniquement dans ce navigateur, sur cet appareil. Exportez-les régulièrement : la sauvegarde est chiffrée avec votre code et peut être restaurée sur un autre appareil (PC ↔ téléphone).

      

        
        
        
      

    

    

      
Importer un relevé bancaire

      
Depuis l'espace client de votre banque, téléchargez vos opérations au format OFX (recommandé, parfois appelé « Money » ou « Quicken »), QIF ou CSV / Excel. Un aperçu s'affiche avant l'import ; les doublons sont ignorés.
